# SafeRoute - Documentación

## Descripción del Proyecto
SafeRoute es un sistema de gestión de transporte seguro que permite:
- Gestión de usuarios y roles
- Gestión de pedidos y solicitudes de transporte
- Integración con servicios externos (WhatsApp, generación de reportes)
- Control y seguimiento de rutas
